# משחק בלש — סימולציית חקירה

משחק דפדפן קליל: בלש/ית בוחר/ת תיק, בודק/ת ראיות, מראיין/ת חשודים בשיחה חופשית, ובסוף מאשים/ה חשוד/ה אחד/ת. התוצאה תלויה בבחירה הנכונה, וזמן החקירה והמוניטין מתעדכנים תוך כדי משחק.

## הרצה

אין תהליך build. פשוט פותחים את `index.html` בדפדפן, או מגישים את התיקייה עם שרת סטטי כלשהו, למשל:

```
python3 -m http.server 8000
```

ואז נכנסים ל-`http://localhost:8000`.

## מבנה הקוד

- `index.html` — נקודת הכניסה, טוענת React/ReactDOM/Babel (מגובבים מקומית תחת `js/vendor/`, ללא תלות ב-CDN) ואת קוד המשחק.
- `js/detective-game/cases.js` — נתוני התיקים (מקרים). כל תיק כולל כותרת, רמת קושי, תיאור, רשימת ראיות, רשימת חשודים (כל חשוד/ה עם משפט פתיחה, רשימת "נושאים" עם מילות מפתח ותשובה, ומשפט חמקני ברירת מחדל), מזהה החשוד/ה האשם/ה, וטקסטים לתוצאה. **להוספת תיק חדש** מספיק להוסיף אובייקט נוסף למערך `DETECTIVE_CASES` — לא נדרש שינוי בלוגיקת המשחק.
- `js/detective-game/app.js` — קומפוננטות ה-React של המשחק:
  - `App` — מנהל אילו תיק נבחר, ומחליף בין מסך בחירת התיקים (`CaseSelectScreen`) לחקירה עצמה (`DetectiveGame`).
  - `DetectiveGame` — מסך החקירה: ניהול ה-state (`useReducer`) עבור זמן, מוניטין, ראיות/ריאיונות שבוצעו, והחשוד/ה שנבחר/ה.
  - `InterviewPanel` — שיחת השאלות והתשובות עם חשוד/ה: הפונקציה `matchSuspectTopic` בודקת אילו מילות מפתח מופיעות בשאלה שהקלדת ומחזירה את תשובת ה"נושא" המתאים ביותר, או משפט חמקני אם שום נושא לא הותאם.
- `css/detective-game.css` — עיצוב כהה ("detective mood").

## מכניקה

- בדיקת ראיה או פתיחת ריאיון עם חשוד/ה חושפות מידע, אבל עולות בשעות חקירה (מוצג כמונה ימים/שעות) ובנקודת מוניטין קטנה.
- בתוך ריאיון פתוח אפשר לשאול שאלות חופשיות בטקסט; כל שאלה עולה שעה נוספת ומקבלת תשובה לפי מילות המפתח שבה.
- בחירת חשוד/ה ולחיצה על "סיום החקירה" פותחות אישור, ולאחר מכן מסך תוצאה: האשמה נכונה מעלה משמעותית את המוניטין, האשמה שגויה פוגעת בו קשות. אפשר לנסות את אותו תיק שוב או לחזור לרשימת התיקים.

## התיקים הקיימים

1. **גניבה בחנות "סטייל סנטר"** (קל) — 3 חשודים, 3 ראיות.
2. **המוות ברחוב הגפן** (בינוני) — 3 חשודים, 4 ראיות.
3. **חצי מיליון שנעלם** (קשה) — 5 חשודים, 4 ראיות.
