# משחק בלש — סימולציית חקירה

משחק דפדפן קליל: בלש/ית חוקר/ת תיק, בודק/ת ראיות, מראיין/ת חשודים, ובסוף מאשים/ה חשוד/ה אחד/ת. התוצאה תלויה בבחירה הנכונה, וזמן החקירה והמוניטין מתעדכנים תוך כדי משחק.

## הרצה

אין תהליך build. פשוט פותחים את `index.html` בדפדפן, או מגישים את התיקייה עם שרת סטטי כלשהו, למשל:

```
python3 -m http.server 8000
```

ואז נכנסים ל-`http://localhost:8000`.

## מבנה הקוד

- `index.html` — נקודת הכניסה, טוענת React/ReactDOM/Babel (מגובבים מקומית תחת `js/vendor/`, ללא תלות ב-CDN) ואת קוד המשחק.
- `js/detective-game/cases.js` — נתוני התיקים (מקרים). כל תיק כולל כותרת, תיאור, רשימת ראיות, רשימת חשודים, מזהה החשוד/ה האשם/ה, וטקסטים לתוצאה. **להוספת תיק חדש** מספיק להוסיף אובייקט נוסף למערך `DETECTIVE_CASES` — לא נדרש שינוי בלוגיקת המשחק.
- `js/detective-game/app.js` — קומפוננטת ה-React של המשחק, כולל ניהול ה-state (`useReducer`) עבור זמן חקירה, מוניטין, ראיות/חשודים שנבדקו, והחשוד/ה שנבחר/ה.
- `css/detective-game.css` — עיצוב כהה ("detective mood").

## מכניקה

- בדיקת ראיה או ראיון חשוד חושפים מידע, אבל עולים בשעות חקירה (מוצג כמונה ימים/שעות) ובנקודת מוניטין קטנה.
- בחירת חשוד/ה ולחיצה על "סיום החקירה" פותחות אישור, ולאחר מכן מסך תוצאה: האשמה נכונה מעלה משמעותית את המוניטין, האשמה שגויה פוגעת בו קשות.
